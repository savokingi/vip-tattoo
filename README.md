# VIP Tattoo Омск — Официальный сайт студии татуировки

Премиальный интерактивный одностраничный сайт для студии художественной татуировки и пирсинга **VIP Tattoo** в Омске (БЦ «Гостиный двор», проспект Карла Маркса, 32).

Сайт разработан в атмосферном готическом/бруталистском стиле (по дизайну проекта `street52`) с множеством интерактивных элементов, плавными анимациями и современными визуальными эффектами.

## ✨ Ключевые особенности и интерактивные элементы
- **Интерактивный холст в Hero-секции**: генерация дымки тату-чернил (`HTML5 Canvas`), реагирующая на движения мыши.
- **Интерактивный калькулятор стоимости**: мгновенный просчет татуировки, перекрытия, пирсинга или лазерного удаления с автозаполнением заявки в WhatsApp.
- **Плавающий превью-курсор**: при наведении на группы услуг появляется интерактивный блок с изображением работ, следящий за курсором.
- **Магнитные кнопки (`Magnetic Buttons`)**: кнопки притягиваются к курсору при наведении.
- **Бегущая строка (`Marquee`)**: бесконечный анимированный баннер со стилями тату и иконками игл.
- **Интерактивная галерея работ**: фильтрация по стилям (*Реализм, Графика, Блэкворк, Пирсинг*) и ховер-эффекты с зумом.
- **Интерактивные карточки мастеров**: готические инициалы, поворачивающиеся и подсвечивающиеся при наведении, с раскрытием цитат мастеров.
- **Анимированные счетчики рейтинга и статистики**: плавный отсчет чисел при скролле.
- **Параллакс и скролл-анимации (`GSAP ScrollTrigger` + `IntersectionObserver`)**: эффекты смещения фонов, готических водяных знаков и плавной проявки элементов.
- **Адаптированность и доступность**: мобильное меню с `clip-path` анимацией раскрытия круглого формата, липкая плашка вызова для смартфонов.

## 🚀 Запуск
Сайт является статическим (Single Page Application). Для запуска достаточно открыть `index.html` в любом браузере или запустить локальный веб-сервер:

```bash
# Использование Python:
python -m http.server 8080

# Или с помощью Node.js (npx serve):
npx serve
```
